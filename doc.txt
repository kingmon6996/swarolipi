--------------------------------------------------------------------------------
2. BACKEND & PROTOCOL API ENDPOINTS (REST API / Flask Engine)
--------------------------------------------------------------------------------

Endpoint: GET /api/v1/verify/:walletAddress
Description: Query the Trust & Reputation Score (0-100) and verification signals for a given Web3 wallet address.
Parameters:
  - walletAddress (path parameter, string): Ethereum / EVM wallet address.
Response: JSON object containing humanVerified, identityVerified, trustScore, and walletOnChainAge.

Endpoint: POST /api/v1/identity/hash
Description: Python Flask REST API endpoint for zero-knowledge deterministic identity hashing (SHA-256 / Poseidon).
Payload: JSON object containing User Name, Date of Birth, and Document ID (zero raw PII storage).
Response: JSON object containing deterministic identity hash for anonymized SSO & emergency account migration.

Endpoint: POST /api/v1/voice/verify
Description: Process audio stream and score user liveness against ElevenLabs 3-sentence challenge.
Payload: Audio recording data + challenge session ID.
Response: JSON object containing livenessScore, verificationStatus (VERIFIED / FAILED), and proof credential.

Endpoint: POST /api/v1/authorize
Description: Third-party dApp authorization gateway endpoint for issuing scoped, time-bounded permission tokens.
Payload: JSON object containing applicationId, requestedPermissions, and scopeDuration.
Response: JSON object containing authorization token and shared anonymized identity hash.
